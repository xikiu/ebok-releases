# Ebok Alpha media

Media for sharing Ebok. The application source is maintained privately.

| Asset | Use |
| --- | --- |
| [Demo video](ebok-alpha-demo.mp4) | A 23-second MP4 showing a real word selection and AI explanation, followed by an Alpha download card |
| [Animated demo](ai-demo.gif) | A 10-second close-up of the same interaction for GitHub and other pages |
| [Share image](social-preview.png) | A 1280 × 640 PNG for social posts and GitHub’s repository social preview |
| [AI popup](ai-explanation.png) | A real completed explanation in the current Alpha UI |
| [Full reader](ai-reading.png) | The AI popup beside the Alice sample |

The demo was recorded at normal speed with the model already downloaded and ready. The Alpha uses Llama 3.2 1B Instruct through WebLLM and WebGPU. First-time AI setup needs a compatible GPU and an approximately 700 MB download. AI answers can be mistaken. [AI setup and privacy](../docs/AI.md).

The demo and reading screenshots use **Alice’s Adventures in Wonderland** by Lewis Carroll. Project Gutenberg lists the sample as public domain in the USA; its original credits and license are retained. [Sample details](../samples/README.md).
